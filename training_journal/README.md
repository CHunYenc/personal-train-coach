# 跑後主觀紀錄

這個資料夾用來補足手錶看不到的資訊：體感、心情、恢復、跑得開不開心。AI 報告可把這些紀錄和 `data/*.fit` 的客觀數據一起看，避免只用配速或心率判斷訓練品質。

## 建議檔名

每次跑後可新增一個 JSON 檔，檔名建議和活動檔 stem 一致：

```text
training_journal/20260515203341.json
```

若當天還沒整理到 FIT 檔，也可先用日期：

```text
training_journal/2026-05-15.json
```

## 欄位範例

```json
{
  "activity_stem": "20260515203341",
  "rpe": 6,
  "enjoyment": 5,
  "mood": "普通",
  "sleep": "普通",
  "soreness": "小腿微緊",
  "notes": "天氣熱，後半段有點煩，但完成後沒有不舒服。"
}
```

## 評分方式

- `rpe`：主觀強度 1-10，1 很輕鬆，10 極限。
- `enjoyment`：開心程度 1-10，1 很不想跑，10 很享受。
- `mood`、`sleep`、`soreness`：用自然語言即可。
- `notes`：記錄天氣、壓力、補給、疼痛、成就感或任何值得回看的細節。

不需要每次寫很多。能穩定寫 1-2 句，比偶爾寫一大篇更有用。
